## What I've been building

| Project | Why it's interesting |
|---|---|
| 🧠 [**SimpleEnglishRag**](https://github.com/parm2006/SimpleEnglishRag) | A local-first RAG system that searches Simple Wikipedia and your own files with hybrid retrieval. |
